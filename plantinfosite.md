# Plant Infomation Site
The general concept of this project is to collect/assimulate the vast amounts of plant information currently available and provide user friendly tools to interface the data. 

\Examples
Create and review a list of desired plants for new restoration site
Create, update and review a species list for site tracking
Create list and use a standard or custtome template to generate plant sale signs

## Objectives
- Collect plant data from many [sources](#sources)
- Standardize, store and allow aggregation of collected data
- Allow free/unlimited access to plant data
- Provide organizational tools like lists, custom forms, spreadsheet exports
